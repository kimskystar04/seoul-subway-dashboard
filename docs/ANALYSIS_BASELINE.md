- 분석 도구: Python 3 + pandas 3.0.6

## 데이터 품질 메모

원본 CSV는 각 데이터 행이 7개 필드(마지막에 빈 필드 하나 포함)를 갖는 반면 헤더 행은 6개 이름만 가진다.
`pandas.read_csv`를 옵션 없이 호출하면 첫 필드(`사용일자`)를 암묵적으로 인덱스로 사용해 나머지 6개 컬럼이 한 칸씩 밀리는 문제가 발생한다.
따라서 `read_csv(..., index_col=False)`를 명시해 컬럼이 밀리지 않도록 고정했다. (`scripts/analyze.py` 참고)

## 계산 방법

1. `사용일자`를 `YYYYMMDD` → 날짜로 변환.
2. `승차총승객수`, `하차총승객수`를 정수로 변환.
3. `전체 이용량 = 승차총승객수 + 하차총승객수`.
4. 역별 합계는 `역명` 기준으로만 그룹화하여 노선과 무관하게 합산.
5. 평일 = 월~금(`date.dayofweek < 5`), 공휴일 구분 없음.
6. 평일/주말 일평균 = 해당 구분에 속하는 날짜별 이용량 합계 ÷ 해당 구분의 날짜 수, 소수 둘째 자리 반올림.
