# 요구사항 (REQUIREMENTS)

- 원본: `claude-code-subway-dashboard-student-guide (2).md` (실습 가이드) 2절/6절 요구사항 섹션
- 확인한 날짜: 2026-09-28
- 비고: 이 실습은 개인 Notion 페이지 대신, 가이드 문서에 명시된 요구사항 원문을 그대로 체크리스트로 옮겨 저장한다.

## 프로젝트 목표
서울 지하철 승하차 데이터를 분석하고 필터와 차트를 제공하는 웹 대시보드를 만든다.

## 필수 기능
- [ ] 날짜 범위 필터
- [ ] 노선 필터
- [ ] KPI 카드 5개: 전체 승차, 전체 하차, 전체 이용량, 평일 일평균, 주말 일평균
- [ ] 이용객 상위 10개 역
- [ ] 노선별 이용량
- [ ] 날짜별 이용량 추이
- [ ] 상세 데이터 표

## 계산 기준
- [ ] 전체 이용량은 승차총승객수 + 하차총승객수로 계산한다.
- [ ] 같은 역명은 노선과 관계없이 합산한다.
- [ ] 평일은 월요일~금요일로 정의하며 공휴일 여부는 구분하지 않는다.
- [ ] 평일·주말 일평균은 선택 기간에 포함된 각 구분의 날짜별 이용량 합계를 해당 날짜 수로 나눈다.

## 화면 요구사항
- [ ] 데스크톱과 모바일에서 사용할 수 있는 반응형 화면
- [ ] 라이트모드와 다크모드 지원
- [ ] 키보드만으로 필터를 조작할 수 있고 포커스 위치가 보여야 함
- [ ] 텍스트와 배경의 색상 대비를 확보해야 함

## 예외 처리
- [ ] 시작일이 종료일보다 늦으면 적용하지 않고 안내 메시지를 표시한다.
- [ ] 필터 결과가 0건이면 오류 대신 데이터 없음 메시지를 표시한다.
- [ ] 하루만 선택해도 KPI·차트·표가 정상 표시되어야 한다.

## 데이터 처리
- [ ] Python과 pandas로 원본 CSV를 분석한다.
- [ ] 분석 결과를 JSON으로 생성한다.
- [ ] 웹은 생성된 JSON만 읽는다.
- [ ] 원본 CSV는 수정하지 않는다.

## 완료 기준
- [ ] 실제 데이터 기준값과 화면 수치가 일치한다.
- [ ] Python 테스트와 JavaScript 테스트가 통과한다.
- [ ] 필터 예외 처리와 다크모드·키보드 접근성을 직접 확인한다.
- [ ] GitHub 저장소에 기록한다.
- [ ] GitHub Pages로 배포한다.

## 제외 범위
- 로그인과 회원 관리
- 데이터베이스
- 백엔드 서버
- React, Vue 등 프런트엔드 프레임워크
- GitHub Pages에서 Python을 실행하는 기능
